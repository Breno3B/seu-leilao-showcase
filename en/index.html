Personal project · Technical showcase

Real estate auction analysis, powered by software engineering.

An evolving platform to organize opportunities, process information and support decisions through traceable workflows.

PythonDjangoPostgreSQLCeleryRedisDocker

The challenge

Real estate auction analysis involves fragmented information, documents, changes and sometimes contradictory data.

Traceable data

Preserving the origin and history of information as part of the workflow.

Asynchronous processing

Keeping long-running work separate from user interactions.

Human review

Making incomplete or conflicting information visible and allowing human judgment.

Architecture and stack

Modular Django monolith with PostgreSQL for persistence and Celery/Redis for asynchronous work.

Sources→Validation→PostgreSQL→Django

Independent tasks can run through Celery/Redis workers.

Engineering approach

The project evolves iteratively with documented decisions, traceability and testing.

AI-assisted development

Generative AI supports specification, implementation, documentation and testing. Proposed changes are reviewed and validated.
